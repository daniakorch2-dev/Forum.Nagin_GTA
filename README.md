# NAGIN GTA — форум (KDE Studio)

Повноцінний форум: реєстрація, вхід, підтвердження email, відновлення пароля, профілі й аватари, 18 ролей з власними
кольорами та правами, теми, відповіді, лайки, скарги, редагування, новини, правила, заявки з розглядом, державні
організації, сповіщення, пошук, адмінпанель та керування грою (онлайн гравців, видача, кіки).

## Запуск (Windows)
1. Встановіть Python 3.10+ (https://www.python.org/downloads/, галочка **Add Python to PATH**).
2. Двічі клацніть `start_forum.bat`. Форум: http://127.0.0.1:8080
3. **Перший зареєстрований користувач автоматично стає Власником.** Зареєструйтесь першим самі.

Нічого більше встановлювати не треба: використовується лише стандартна бібліотека Python. База — файл `data/forum.db`.

## Пошта (підтвердження email, відновлення пароля)
Поки SMTP не налаштовано, листи з посиланнями виводяться у вікні сервера й зберігаються в `data/outbox/`.
Для реальних листів заповніть `smtp` у `config.json` (host, port, security: starttls/ssl, user, password, from)
і вкажіть справжній `base_url`. Для сайту в інтернеті ставте `"secure_cookies": true` і HTTPS через проксі (nginx/Caddy).

## Керування з консолі
`python manage.py setrole <логін> <роль>` · `verify <логін>` · `passwd <логін>` · `roles` · `key`

## Зв'язок із грою
1. Адмінпанель → **Гра** (лише для Власника видно ключ) або `python manage.py key`.
2. У `nagin_gta/server/config.lua` у `Config.forum` вкажіть `url` форуму й цей `key`.
3. Після перезапуску ресурсу на сторінці «Гра» з'являться гравці онлайн, а команди з форуму виконуватимуться в грі за ~5 сек.
Ролі з правом `game.manage`: Власник, Заступник власника, головні куратори, Розробник тощо (налаштовується в «Ролі та права»).

## Безпека
Паролі — scrypt; сесії — HttpOnly SameSite cookie (у БД лише хеш); CSRF-токени й перевірка Origin; ліміт спроб входу;
екранування всього користувацького тексту (XSS); CSP; усі права перевіряються на сервері; аватари перевіряються за вмістом файлу.
